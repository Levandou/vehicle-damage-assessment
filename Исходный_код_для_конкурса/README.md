# Анализ повреждений автомобиля по фотографиям

Исходный код исследовательского прототипа. Сегментация деталей реализована на DeepLabV3+, выделение повреждений — на Mask R-CNN. В состав также входят детекция ключевых точек, сопоставление двух ракурсов, работа с трёхмерной моделью и оценка скрытых повреждений.

## Состав

- `cv_models.py` — загрузка и применение моделей компьютерного зрения;
- `damage_pipeline.py`, `damage_3d.py` — обработка снимка, геометрия и оценка повреждений;
- `near_pipeline.py`, `near_matchers.py`, `near_pose.py` — анализ пары снимков;
- `hidden_damage.py` — обработка оценки скрытого риска;
- `run_two_view.py` — пример запуска для двух снимков.

## Запуск

Для Windows список зависимостей приведён в `requirements_windows.txt`. После установки зависимостей разместите в папке `some_models` следующие файлы обученных моделей и трёхмерной геометрии:

```
some_models/
  details_deeplabv3plus.pt
  damages_maskrcnn.pth
  points_hrnet_w32.pt
  hyundai_solaris.glb
  xgboost_hidden_damage_model.pkl  # необязательно
```

Затем выполните:

```bash
python run_two_view.py --far path/to/far.jpg --near path/to/near.jpg --output results
```

Весовые файлы, трёхмерная модель и фотографии не входят в этот архив. Без них анализ снимков не запускается. Публикация исходников сама по себе не обеспечивает воспроизведение численных результатов: для этого также нужны обученные веса и проверочная выборка.
